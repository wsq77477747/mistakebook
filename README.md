# SQL 错题本

本目录用于把 SQL 刷题中的错题**分门别类**整理，并汇总成一个带 **趋势分析 / 智能检索 / AI 助手** 的 HTML 页面。

## 2026-08-29：账号与复习系统升级

- 首页改为 **今日复习**：先回忆题目，再查看答案，最后选择“忘记 / 模糊 / 掌握 / 轻松”。
- 系统会根据每次反馈自动计算下一次复习日期，不再只依赖“未掌握 / 复习中 / 已掌握”三个静态状态。
- 新增 SQLite 数据库，保存账号、错题、复习历史、间隔参数、同步版本和软删除记录。
- 新增账号隔离和登录会话；第一个注册账号会自动导入当前 `错题库/` 中的 Markdown。
- 新增增量同步 API，网站和后续微信小程序可共用同一账号、错题与复习进度。
- 手机端改为底部四栏导航，分类侧栏不再占据首屏。

首次升级后，双击 `打开错题本.bat`，在登录窗口点击“创建账号并导入本地错题”。数据库默认保存在 `data/sql_review.db`，Markdown 文件继续作为本地备份保留。同步协议和部署边界见 [docs/CLOUD_SYNC.md](docs/CLOUD_SYNC.md)。

## 每次怎么打开

**双击 `打开错题本.bat`**，它会：

1. 运行 `rebuild_index.py` 重新扫描 `错题库/`，按知识点分类，生成最新 `index.html`；
2. 检测并启动本地服务 `server.py`（若已在运行则跳过）；
3. 用浏览器打开 `http://127.0.0.1:8765/`。

> 本地服务默认只监听 `127.0.0.1`，不暴露到外网。账号、复习和同步功能必须通过该服务使用，不能直接双击 `index.html`。不想要服务时双击 `停止服务.bat` 即可。
> 关闭「SQL错题本-AI服务」最小化窗口也能停止服务。

## 页面功能

- **✅ 今日复习**：展示到期错题，先回忆后看答案，用四档反馈自动安排下次复习，并保留最近复习记录。
- **☁️ 账号同步**：错题、掌握状态、间隔参数和复习事件保存在 SQLite，可供网站和小程序增量同步。
- **📚 错题列表**：按知识点分类展示全部错题，侧栏分类导航 + 每题跳转入口 + 快速过滤。
- **📊 趋势分析**（本地离线）：累计错题曲线、每月新增、知识点/错误类型/难度分布、高频复错榜。
- **🔍 智能检索**（本地离线）：题号/标题/知识点/错因全文检索，支持同义词命中（如"不等于"→"WHERE 条件过滤"），并给出相关错题推荐。
- **🤖 AI 助手**（右下角浮窗，两个模式）：
  - 💬 对话：自然语言问答、错题归因、复习计划；
  - ➕ 新增错题：粘贴文本**和/或上传题目截图** → AI 自动识别/抽取字段、归类、写 markdown → **预览确认** → 一键入库并自动重建。
  均需先配置 API Key，见下。

## 配置 AI 助手（可选，Key 可随时更换）

1. 打开页面后，点击右下角 🤖 → 右上角 ⚙️；
2. 填写 **API Base URL**（默认火山方舟 `https://ark.cn-beijing.volces.com/api/v3`）、**API Key**、**模型名**；
3. 首个注册账号是站点管理员。管理员保存后，Key 会写入本机 `ai_config.json`，不会出现在网页里；普通账号可以使用已配置的 AI，但不能查看或修改 Key。
4. 保存前会自动「🔌 测试连接」：**测试通过才允许保存**，Key 为空或模型不可用会拒绝保存并提示原因；
   表单 Key 留空时自动沿用已保存的 Key 进行测试。
5. 设置弹窗顶部和右下角 AI 浮窗头部都会显示**当前使用模型**，切换预设后可立刻看到变化。
6. 未配置 Key 时，本地"趋势分析 / 智能检索"照常可用，仅 AI 相关（对话 / 自动整理）不可用。

> 支持的 LLM 需为 OpenAI 兼容接口（火山方舟 / DeepSeek / 通义 / OpenAI / 智谱 等均可，改 Base URL 即可）。
> Base URL 可以只填域名前缀（自动补 `/chat/completions`），也可以直接填完整端点，两种都能识别。

### 配置选项（多套预设，一键切换）

设置弹窗底部有 **💾 配置选项**：

- 填好 Base URL / Key / 模型后点 **「＋ 保存为选项」**，命名并固化这套配置（Key 留空则沿用当前 Key）；
- 之后想换模型，点选项上的 **应用** 即可一键切换，**删除** 可移除；
- 适合把「免费文本 / 免费视觉 / 付费大模型」等多套方案各存一份，随时切换。

### 智谱 API 报错速查

| 报错码 | 含义 | 处理 |
|--------|------|------|
| 400 / 1214 modelCode 不存在 | 模型名格式不对 | 用官方全小写连字符，如 `glm-4.7-flash` |
| 429 / 1113 余额不足或资源包不足 | 账号资源包不覆盖该模型 | 到智谱控制台确认资源包/实名是否完成 |
| 429 / 1305 访问量过大 | 平台高峰限流（免费模型常见） | 稍后重试即可，本工具已内置自动重试（3 次、退避 2/4/6 秒） |


## 用 AI 自动整理新增错题（推荐）

1. 点击右下角 🤖 → 切换到「➕ 新增错题」；
2. 把原始内容粘贴进输入框（题目描述 / 你写的错误 SQL / 报错信息均可，越全整理越准）；
3. 点「AI 整理归类」——AI 会抽取题号、标题、知识点、难度、来源、错误类型、状态、一句话错因，并生成 markdown 正文；**知识点会优先匹配已有分类**，匹配不上才新建；
4. 在预览表单里核对/修改（所有字段和正文都可编辑），必要时点「重新生成」；
5. 点「✅ 确认入库」→ 自动写入 `错题库/<知识点>/` 并重建索引，页面刷新后即可看到。

## 图片识别：直接把题目截图交给 AI

1. 在「➕ 新增错题」里点 **📷 上传题目截图**（或直接 **Ctrl+V 粘贴**截图）；
2. 缩略图出现后点「AI 整理归类」——AI 会识别图片中的题目描述、数据表、SQL 和报错信息，生成 markdown 正文；
3. 预览确认后入库，**原始截图会自动保存到** `错题库/<知识点>/`（如 `2026-08-27_SQL10_原始截图.png`），方便回看。

> 图片识别需要**支持视觉的模型**（如你配置的 GLM-5.3-Flash 原生多模态；火山方舟可用豆包 vision 系列）。截图会自动压缩到最长边 1500px 再识别，避免超出模型限制。

> 也可手动新增：复制 `模板.md` 改名放 `错题库/`，双击 bat 重建。两种方式效果相同。

## 以后新增错题的步骤

1. 复制根目录的 `模板.md`，改名为 `日期_题号_标题.md`；
2. 放到 `错题库/` 下对应知识点子目录（没有就新建，分类以文件内「知识点」字段为准）；
3. 填写头部元信息（题号/标题/知识点/难度/日期/来源/错误类型/状态/做错次数/重错日期/一句话总结）；
4. 按模板写正文：题目 → 我的错误写法 → 正确写法 → 错因分析 → 知识点总结；
5. 双击 `打开错题本.bat`，页面、趋势、检索自动更新。

## 元信息字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| 题号 | 是 | 如 SQL9 / 牛客 23 / LC 175 |
| 标题 | 是 | 题目简短名称 |
| 知识点 | 是 | 分类依据，如 `WHERE 条件过滤`、`JOIN 连接`、`窗口函数` |
| 难度 | 建议 | 简单 / 中等 / 困难 |
| 日期 | 是 | 做错日期，格式 `YYYY-MM-DD` |
| 来源 | 建议 | 牛客 / LeetCode / 力扣 / 面试等 |
| 错误类型 | 建议 | 语法错误 / 逻辑错误 / 函数用法 / NULL陷阱 等 |
| 状态 | 建议 | 未掌握 / 复习中 / 已掌握 |
| 做错次数 | 建议 | 数字，默认 1；大于 1 会进「高频复错榜」 |
| 重错日期 | 建议 | 历次做错日期，逗号分隔（供趋势统计频次） |
| 一句话总结 | 建议 | 一句话点出错因，会展示在卡片上 |

## 维护小技巧

- 正文固定用 `## 标题` 分节，脚本会自动识别：题目 / 我的错误写法 / 正确写法 / 错因分析 / 知识点总结。
- 代码块用三个反引号包裹（写 `sql` 会获得语法高亮），表格直接写 Markdown 表格。
- 同义词映射在 `assets/template.html` 的 `SYN` 对象里，需要扩展检索能力时可自行增补。
